# 交接说明（换电脑 / 换人接手先看这里）

> 目标：在任何一台 Windows 上，5 分钟内恢复"能编译、能验证、知道该改哪"的状态。

## 1. 这是什么

Windows 外设电量托盘工具（C# 5 / .NET Framework 4.0 / WinForms，零第三方依赖）。
实测设备：MCHOSE A7 V2 Pro+、西伯利亚 K02BS、罗技 G PRO Wireless（经接收器）。

- 当前版本：**1.4.0**（`src/AssemblyInfo.cs` 是唯一真源）
- 分支 `main`，标签 `v1.4.0`
- 仓库：https://github.com/xianzhige99/WirelessBattery

## 2. 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| 运行时 | .NET Framework 4.x（系统自带，**不需要装 SDK**） |
| 编译器 | 系统自带 `csc.exe`（`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\`） |
| 可选 | Git、PowerShell 5.1（系统自带） |

## 3. 三条命令确认环境没坏

```
build.ps1 -Clean -Strict      → Build OK，零警告
tests\run-tests.ps1           → ALL PASS（86 项，不碰硬件）
bin\WirelessBattery.exe --once → 生成 scan.txt，可看设备识别结果
```

## 5. 当前已知限制（不要当 bug 反复查）

1. **K02BS 只连 2.4G 时显示「未确认」**：2.4G 链路不回报耳机状态，接收器也不给（`0xFF90` 恒 `AC F8`）。
   这是刻意取舍，见 D13/D16。
2. **罗技本体 `046D:4079` 读不到**：`HID VHF Driver`、`out=0`，只能经接收器 `C539` 取。
3. **同型号多设备共用一张卡**：键是型号级的，见 D1/D2。

## 7. 换电脑时，什么会跟着走

| 内容 | 通过 Git | 通过"整个文件夹拷贝" | 说明 |
|---|---|---|---|
| 源码 / 文档 / 脚本 / 测试 | ✅ | ✅ | 主要资产，都在 Git 里 |
| `bin/` 构建产物 | ❌ | ❌（已排除） | 三条命令重新生成即可 |
| `settings.ini` | ❌ | ❌（已排除） | 含个人设备名与电量历史；需要就手动拷 |
| `.workbuddy/memory/` | ❌（被 .gitignore 排除） | ✅ | 只是工作日志；关键结论已沉淀进 `docs/02` |
| 专家 / 技能 / 连接器授权 | — | — | 跟账号走，新设备登录后按需重新授权连接器 |

> 换句话说：**只要 Git 里有 `docs/`，换机器就不会丢"为什么这么改"**。
> 这也是为什么每次决策都要写进 `docs/02-决策记录.md`，而不是只留在对话里。
